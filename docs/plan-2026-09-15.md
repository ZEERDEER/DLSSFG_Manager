# DLSSG SM86 管理器实施计划

创建日期：2026-09-15

## 一、目标与技术选型

制作一个中文 Windows 便携管理器，提供：

- 扫描游戏，定位真正运行的 EXE。
- 自动推荐 DLL，也允许手动选择。
- 勾选游戏后一键安装、更新和卸载。
- 从上游下载最新版，直接覆盖已安装的旧插件。
- 自动备份，保留配置，支持恢复备份。

**采用 C# + WinForms + .NET Framework 4.8，目标平台为 Windows x64。**

这个项目主要涉及目录扫描、网络下载和文件操作，C# 开发维护最方便。WinForms 使用系统控件和字体，管理器可以保持较小体积；Windows 10 1903 起及 Windows 11 已自带兼容运行环境。相比之下，C++ 开发成本更高，现代 .NET 自包含发布会明显增加体积。

管理器独立分发为绿色 ZIP，补丁按需下载，也支持导入本地上游目录。配置、缓存、备份和安装记录保存在便携目录的 `data` 文件夹中。

## 二、游戏扫描与 DLL 推荐

### 游戏目录识别

首版支持：

- 自动读取 Steam 注册表位置、`libraryfolders.vdf` 和游戏安装清单。
- 添加自定义扫描目录，覆盖非 Steam 游戏。
- 手动选择或拖入 EXE。
- 后台扫描、取消扫描和重复路径合并。

每个游戏分别记录“安装目录”和“渲染 EXE”。补丁始终安装到渲染 EXE 同目录。

优先识别已知游戏路径、UE 的 `Binaries\Win64` 和 `*-Win64-Shipping.exe`。排除启动器、崩溃报告程序及 32 位 EXE；存在多个合理候选时，在界面中选择实际 EXE。

内置以下规则，路径相对于扫描到的游戏安装目录：

| 游戏 | Steam AppID | 渲染 EXE 相对路径 | 默认 DLL |
|---|---:|---|---|
| 剑星 | 3489700 | `SB\Binaries\Win64\SB-Win64-Shipping.exe` | `version.dll` |
| 赛博朋克 2077 | 1091500 | `bin\x64\Cyberpunk2077.exe` | `dxgi.dll` |
| 仁王 3 | 3681010 | `Nioh3.exe` | `winmm.dll` |

三条路径已在本机核实，程序不写死盘符。

### DLL 选择规则

新安装按以下顺序推荐：

1. 用户保存的选择。
2. 已知游戏规则，包括上述三款游戏。
3. PE 普通导入、延迟导入中的候选 DLL。
4. 没有明确线索时，默认推荐 `version.dll`，标注“待验证”。

在静态证据相同的情况下，遵循上游顺序：

`version → winmm → dbghelp → dinput8 → dxgi → d3d12`

静态导入只能辅助推荐。赛博朋克的 EXE 导入 `version.dll`，仍应优先使用用户实测有效的 `dxgi.dll`。

界面采用“游戏多选 + DLL 单选”。每个游戏只启用一个本项目代理；选择备用 DLL 时复制 `alternatives` 中对应文件，不能把 `version.dll` 直接重命名。

## 三、安装、更新与卸载行为

### 主界面

游戏列表显示：游戏名称、渲染 EXE、当前代理、推荐代理、补丁版本和操作状态。

主要按钮为：

**扫描游戏、添加目录/EXE、导入本地补丁、一键安装、检查更新、更新已安装插件、一键卸载。**

辅助入口提供打开游戏目录、打开 INI、打开日志目录和恢复备份。日志目录读取实际 INI 设置。

### 一键安装与覆盖

- 对勾选游戏安装一个选定代理 DLL，以及首次安装所需的 `dlssg_sm86.ini`。
- 已有 INI 原样保留；缺失时补齐默认配置。
- 根据用户要求，对明确选中的旧 DLL，包括无法识别版本的文件，**自动备份后直接覆盖，不增加接管确认**。
- 已安装插件的更新保留代理名称：仁王 3 更新 `winmm.dll`，赛博朋克更新 `dxgi.dll`。
- 切换代理时，移除已记录且校验一致的旧代理，再部署新代理。
- 同目录其他 DLL 不按名称批量清理。例如赛博朋克自带的微软 `dbghelp.dll` 必须保留。

已有插件优先通过安装记录、已知文件校验值识别；未知版本则结合 INI、游戏规则和实际存在的文件确定槽位。仍有歧义时，让用户选择当前代理，避免同时留下两个补丁。

### 一键卸载与恢复

- 将所选补丁 DLL 和 INI 备份后移出游戏目录。
- 已明确选中的手工安装旧插件，也支持直接卸载。
- 历史旧补丁保留在备份目录，卸载时不自动恢复旧补丁。
- 对已管理但被外部修改的 DLL，停止该游戏的卸载并保留 INI，显示冲突原因。
- “恢复备份”作为独立操作，可恢复此前 DLL 和配置。

### 文件操作可靠性

安装、更新、切换和卸载均按单个游戏执行事务：

1. 检查游戏进程、文件占用和目录写入权限。
2. 保存并校验备份，持久化待执行记录。
3. 在目标目录暂存文件并完成替换。
4. 校验结果，提交安装记录。

失败时恢复该游戏的原状态；其他游戏继续处理。程序异常退出后，下次启动依据待执行记录恢复。备份失败时不覆盖文件。

### GitHub 更新

更新源固定为 [sdli1995/dlssg_for_sm86](https://github.com/sdli1995/dlssg_for_sm86)，首版更新对象为补丁 DLL。

已核实最新稳定 Release 为 `0.3.0`，目前没有附加下载资产。因此采用：

1. 查询最新稳定 Release。
2. 将 tag 解析为固定 commit。
3. 获取该 commit 的文件清单。
4. 按需下载对应 DLL、默认 INI 和第三方声明。
5. 校验大小和 Git blob hash，另外保存 SHA-256。
6. 校验完成后更新勾选游戏。

不下载包含历史版本的完整仓库压缩包。默认使用根目录当前运行库系列，不混用 `310.1` 和历史归档。

DLL 没有可靠的 Windows 文件版本信息，因此以 **tag、commit、代理名和 SHA-256** 记录版本。手工安装且无法匹配的文件显示“未知版本”。

下载失败、校验失败或 API 限流时保持游戏文件原状；离线可使用已校验缓存或本地导入包，并显示来源和最后检查时间。

## 四、实施顺序与内部接口

在上游仓库中新增独立管理器目录，划分 WinForms 界面、业务核心和测试项目。

- [ ] **搭建基础窗口与持久化。** 完成游戏列表、单选 DLL、批量操作状态，以及便携数据目录。
- [ ] **实现扫描和推荐。** 完成 Steam 清单解析、EXE 定位、三款游戏规则和 PE 导入分析。
- [ ] **实现本地补丁安装闭环。** 完成导入、备份、安装、覆盖、切换、卸载及异常恢复。
- [ ] **接入上游更新。** 完成稳定 Release 查询、固定 commit 下载、校验与按已安装代理更新。
- [ ] **完成打包与验收。** 输出便携 ZIP、中文使用说明，并验证干净 Windows 环境运行。

核心接口职责：

| 模块 | 输入与输出 |
|---|---|
| 游戏扫描 | 扫描根目录 → 游戏、AppID、渲染 EXE、定位依据 |
| 代理推荐 | 游戏信息和现有安装 → 推荐 DLL、理由、候选列表 |
| 补丁来源 | 本地目录或上游 Release → 可部署文件和版本信息 |
| 安装服务 | 游戏、代理、操作类型 → 执行结果或可恢复错误 |
| 安装记录 | 目标目录、部署哈希、配置归属、备份和事务状态 |

安装记录以规范化后的渲染 EXE 目录为唯一管理目标，避免多个列表条目重复操作同一目录。界面通过业务接口操作文件。

## 五、验收标准

- **目录定位：** 三款示例游戏定位正确；覆盖多 Steam 库、中文和空格路径、启动器干扰及重复扫描。
- **代理选择：** 仁王 3 默认 `winmm.dll`、赛博朋克默认 `dxgi.dll`、剑星默认 `version.dll`；手动选择可保存。
- **安装更新：** 使用对应代理文件；更新保留原 INI；未知旧 DLL 自动备份后覆盖；重复安装结果一致。
- **切换卸载：** 切换后仅保留一个本项目代理；卸载移除选定插件；微软 `dbghelp.dll` 等无关文件保持完整。
- **异常恢复：** 覆盖失败、文件占用、空间不足、下载中断和程序异常退出均可恢复；卸载冲突不会单独移除 INI。
- **更新兼容：** 覆盖无 Release 附件、tag 解引用、校验失败、离线缓存和 API 限流场景。
- **运行体验：** 扫描与下载不阻塞窗口；在只有 .NET Framework 4.8 的测试环境运行便携包。

安装状态表示文件部署完成。实际帧生成效果由用户启动游戏验证；默认日志等级可能只记录错误，空日志不作为失败依据。

首版不包含帧生成内核修改、自动启动游戏试错、完整 INI 可视化编辑器或管理器自身自动更新。
